# VorteX — Calculator for IT Companies

Десктопное приложение Windows Forms для управления зарплатным фондом IT-компании. Позволяет вести список сотрудников, фильтровать их по отделу и грейду, а также рассчитывать зарплату «чистыми» с автоматическим применением актуальных ставок НДФЛ.

---

## Обзор

VorteX — учебный проект, реализующий базовый цикл работы с кадровыми данными: создание записи о сотруднике, просмотр и фильтрация списка, расчёт итоговой суммы выплаты после налогового вычета.

Приложение хранит все данные только в оперативной памяти. Базы данных и внешние хранилища не используются.

### Возможности

**Форма 1 — Список сотрудников**

- Добавление сотрудника через диалоговое окно (имя, оклад, отдел, грейд)
- Удаление выбранного сотрудника с подтверждением
- Поиск по имени в реальном времени
- Фильтрация по отделу: `Backend`, `Frontend`, `DevOps`, `QA`
- Фильтрация по грейду: `Junior`, `Middle`, `Senior`
- Сводная статистика по текущей выборке: количество сотрудников, средний оклад, суммарный фонд «на руки»
- Переход к расчёту зарплаты для выбранного сотрудника

**Форма 2 — Калькулятор зарплаты**

- Отображение данных сотрудника: имя, отдел, грейд, расчётный период
- Ввод нового оклада с клавиатуры; подтверждение кнопкой или клавишей `Enter`
- Автоматический пересчёт таблицы при изменении оклада
- Мини-дисплей с крупным отображением суммы «на руки»
- Изменённый оклад сохраняется обратно в список Формы 1

## Расчётная логика

Ставка НДФЛ определяется автоматически по годовому доходу:

```
оклад × 12 < 2 400 000 ₽   →   ставка 13%
оклад × 12 ≥ 2 400 000 ₽   →   ставка 15%
```

Таблица расчёта, отображаемая в Форме 2:

| Строка | Описание |
|--------|----------|
| Оклад | Введённая сумма |
| НДФЛ | `round(Оклад × Ставка)` |
| На руки (нетто) | `Оклад − НДФЛ` |
| Страховые взносы | `round(Оклад × 0.30)` — справочно |
| Расходы работодателя | `Оклад + Взносы` |
| Ставка НДФЛ | Применённый процент с пояснением |

## Запуск

1. Открыть `VorteX - Calculator for IT companies.slnx` в Visual Studio
2. Убедиться, что целевая платформа — `.NET Framework 4.7.2` или выше
